How roles work here

SocialConnect does not create automatic application roles. Existing Django groups are the source of truth for reusable permission sets.

  • Staff status gates access to this admin site.
  • Superuser status grants all model permissions.
  • Group and user permissions are managed through Django's existing admin forms.
  • This page displays access only; it does not grant or change privileges.
